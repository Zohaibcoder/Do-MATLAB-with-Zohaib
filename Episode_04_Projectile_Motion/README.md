# Episode 04 — Projectile Motion

MATLAB project files for **Episode 04** of the **Do MATLAB with Zohaib** YouTube series.

In this episode, we use MATLAB to simulate and visualize the motion of a projectile.

## 🎯 What You'll Learn

* Working with vectors in MATLAB
* Creating and manipulating arrays
* Element-wise operations
* Calculating projectile motion
* Using `plot()` to visualize data
* Creating a simple projectile trajectory simulation

## 🚀 Project

We build a **Projectile Motion Simulation** in MATLAB.

The program calculates the horizontal and vertical motion of a projectile and plots its trajectory.

The project demonstrates how MATLAB can be used to turn mathematical equations into a simple engineering simulation.

## 🛠️ MATLAB Concepts Used

* Variables
* Vectors
* Arrays
* Element-wise operations
* Mathematical functions
* `plot()`
* Basic graph customization
