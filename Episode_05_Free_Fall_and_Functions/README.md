# Episode 05 — Free Fall + Functions

MATLAB project files for **Episode 05** of the **Do MATLAB with Zohaib** YouTube series.

In this episode, we simulate the motion of a freely falling object using MATLAB and learn how to create and use our own MATLAB functions.

## 🎯 What You'll Learn

- Simulating free fall using MATLAB
- Working with mathematical equations
- Creating and using MATLAB functions
- Passing inputs to functions
- Returning outputs from functions
- Visualizing motion using plots
- Using `subplot()` to display multiple graphs

## 🚀 Project

We build a **Free Fall Simulation** in MATLAB.

The program calculates and visualizes the motion of a falling object, while introducing MATLAB functions to organize and reuse code.

## 🛠️ MATLAB Concepts Used

- Variables
- Mathematical operations
- Functions
- Function inputs and outputs
- Vectors and arrays
- Plotting
- `subplot()`
